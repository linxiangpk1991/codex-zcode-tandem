# 常见问题

[English](faq.md) · [返回首页](../README.zh-CN.md)

## Codex ZCode Tandem 是什么？

一个 Windows Codex 技能和本地 ACP 适配器。Codex 确定范围并检查结果，原生 ZCode 使用用户自己的 Coding Plan 完成约定的实现、测试或审查。适合已经同时使用这两个工具的人。

## 它会替代 Codex 或 ZCode 吗？

不会。两者需要分别安装。Tandem 连接的是一段具体的协作流程，你选择的 Codex 总控模型不变。

## 这是官方集成吗？

不是，这是独立的社区项目。名称说明它连接哪些工具，不代表获得官方背书。

## 比复制提示词多了什么？

保留会话、结构化进度、排队追问、明确暂停和原生工作流恢复，让反复交接更容易检查。如果任务很小，或者只要一次回答，复制提示词或只用一个工具也很合适。我们没有宣称经过测量的 token 节省或提速比例。

## ZCode 干活时，Codex 能随时询问和提建议吗？

可以立即读取进度，也可以随时提交追问或纠偏。消息在下一个安全前台回合边界、剩余阶段之前处理，不能打断正在执行的工具。已经运行的工作流角色，需要明确修订，或暂停、读回后续接。

## 能用自己的 Coding Plan 吗？会提供 API Key 吗？

使用你自己已经安装、登录的原生 ZCode。项目不提供账号、订阅或 API Key，也不自动切到付费 API。账号可用性与模型权限取决于 ZCode 和你的套餐。

## 必须有 provider_config.json 吗？

不需要。它是可选自定义供应商配置，不是 Coding Plan 登录文件。显式传入的路径必须存在，默认路径没有这个文件则允许继续。请用原生连接探针检查实际配置。

## “本地运行”是否代表提示词不会离开电脑？

不是。适配器在本地运行，原生 ZCode 仍通过服务进行模型推理，其数据处理与账号条款继续适用。Tandem 的工具检查也不等于操作系统沙箱。

## 支持哪些模型和系统？

Windows、Node 24.19.0、ACP 0.65.1。已验证的原生基线为桌面版 3.14.4.7912 / CLI 0.16.9。GLM-5.3 和 GLM-5.3-Flash 默认使用 max 思考强度。不宣称支持 macOS、Linux 或任意供应商、模型组合。

## 暂停会撤销修改吗？恢复能保证只执行一次吗？

都不能保证。暂停停止当前任务，已完成的效果会保留。恢复或修订可以复用原生节点结果，但结果未知的外部操作仍需先读回，并检查哪些节点命中了缓存。

## 会覆盖我已经安装的 zcode-native 吗？

不会。公开版安装为 codex-zcode-tandem，源码和入口独立。同时保留两个技能时，请明确调用需要的那个。两者之间不会自动同步。

## 怎样反馈问题？

提交 Issue，写明版本、最小复现、期望与实际结果，以及脱敏错误片段。不要上传完整原生会话、登录文件或私人项目内容。敏感问题见[安全说明](../SECURITY.md#简体中文)。
