# Codex ZCode Tandem 常见问题

[English](faq.md) · [返回首页](../README.zh-CN.md)

## Codex ZCode Tandem 是什么？

Codex ZCode Tandem 是连接 OpenAI Codex 与原生 ZCode 的 Windows 开源技能，使用 ACP（Agent Client Protocol）传递任务。Codex 确定范围并检查结果，原生 ZCode 使用用户自己的 GLM Coding Plan 完成约定的实现、测试或审查。适合已经同时使用这两个工具的人。

## 它会替代 Codex 或 ZCode 吗？

不会。两者需要分别安装。Tandem 连接的是一段具体的协作流程，你选择的 Codex 总控模型不变。

## 这是官方集成吗？

不是，这是独立的社区项目。名称说明它连接哪些工具，不代表获得官方背书。

## 比复制提示词多了什么？

保留会话、结构化进度、排队追问、明确暂停和原生工作流恢复，让反复交接更容易检查。如果任务很小，或者只要一次回答，复制提示词或只用一个工具也很合适。我们没有宣称经过测量的 token 节省或提速比例。

## ZCode 干活时，Codex 能随时询问和提建议吗？

可以立即读取进度，也可以随时提交追问或纠偏。纠偏使用协商后的原生 now/next 能力，追问作为后续回合执行。原生引擎仍可能把纠偏排到安全边界；接收消息不等于修改已落实。已经运行的工作流角色，需要明确修订，或暂停、读回后续接。

## 能用自己的 Coding Plan 吗？会提供 API Key 吗？

使用你自己已经安装、登录的原生 ZCode。项目不提供账号、订阅或 API Key，也不自动切到付费 API。账号可用性与模型权限取决于 ZCode 和你的套餐。

## 必须有 provider_config.json 吗？

不需要。它是可选自定义供应商配置，不是 Coding Plan 登录文件。显式传入的路径必须存在，默认路径没有这个文件则允许继续。请用原生连接探针检查实际配置。

## “本地运行”是否代表提示词不会离开电脑？

不是。适配器在本地运行，原生 ZCode 仍通过服务进行模型推理，其数据处理与账号条款继续适用。Tandem 的工具检查也不等于操作系统沙箱。

## 支持哪些模型和系统？

Windows、Node 24.19.0、ACP 0.85.3。v1.6.0 已验证的原生基线为桌面版 3.18.2.10443 / CLI 0.17.1。GLM-5.3 和 GLM-5.3-Flash 默认使用 max 思考强度。不宣称支持 macOS、Linux 或任意供应商、模型组合。

## 暂停会撤销修改吗？恢复能保证只执行一次吗？

都不能保证。暂停停止当前任务，已完成的效果会保留。恢复或修订可以复用原生节点结果，但结果未知的外部操作仍需先读回，并检查哪些节点命中了缓存。

## 会覆盖我已经安装的 zcode-native 吗？

不会。公开版安装为 codex-zcode-tandem，源码和入口独立。同时保留两个技能时，请明确调用需要的那个。两者之间不会自动同步。

## 怎样反馈问题？

提交 Issue，写明版本、最小复现、期望与实际结果，以及脱敏错误片段。不要上传完整原生会话、登录文件或私人项目内容。敏感问题见[安全说明](../SECURITY.md#简体中文)。

## 独立代码审查默认启用吗？

从 1.5 起，开发请求默认使用新原生会话复审。问题或检查未通过就不能交付；两轮修复后仍未解决会返回阻塞信息。只读查询不进入闭环。

## 这是让 Codex 改用 GLM，还是让 Codex 调用 ZCode？

是让两个工具协作。Codex 继续使用你选定的总控模型，原生 ZCode 使用你的 GLM Coding Plan 完成实现和测试。它不会替换 Codex 的模型、代理 Codex API，也不会把一个服务的订阅转给另一个服务。

## Tandem 是 MCP 服务器吗？

不是。Tandem 是 Codex 技能，配套一个本地 ACP 适配器，使用 ACP 传递 ZCode 会话和控制消息。请按 [Windows 安装指南](../references/installation.zh-CN.md)安装技能，不需要把它配置成 MCP 服务器。

## 免费吗？需要两个工具各自的账号吗？

Tandem 代码采用 MIT 许可证，项目本身不收费。你仍需具备 Codex 使用权限，以及可用的 ZCode 账号和相应模型权限。两边的订阅、额度与数据处理条款分别适用。独立审查可能增加 ZCode 用量，项目不保证节省费用。

## 没有视觉模型，ZCode 适合验证网页吗？

在任务提供合适工具时，ZCode 可以执行已授权的功能检查，例如项目已有的浏览器测试，并检查文本或 DOM 证据。截图的视觉效果仍需具备视觉能力的总控验收；图片哈希只能证明交接的是哪些文件，不能证明排版正确。
